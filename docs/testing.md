# Testing Plan

Testing should happen one subsystem at a time before full integration.

## Mechanical tests

- Check buoyancy.
- Check stability with expected payload.
- Check frame rigidity.

## Motor tests

- Verify ESC wiring.
- Calibrate throttle range.
- Test each thruster separately.
- Test differential steering at low power.

## Sensor tests

- Check GPS output.
- Check compass/IMU heading.
- Check wind-sensor readings.
- Record noisy or invalid readings.

## AI tests

- Test known waste images.
- Test different distances.
- Test bright and low-light scenes.
- Record precision, recall, mAP and FPS.

## Water tests

Begin in controlled, calm water with a recovery method available. Test first with no waste, then with known floating objects, and finally with mixed waste.

## Results

Actual measurements will be added after testing. This avoids presenting assumed or simulated values as real-world results.
